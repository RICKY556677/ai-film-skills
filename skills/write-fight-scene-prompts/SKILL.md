# AI电影打斗提示词

把用户的场景写成可执行的动作调度。优先保证动作清楚、空间稳定和状态连续，再补风格、光线与特效。

## 工作流程

### 1. 确认输出规格

先从用户材料中提取以下信息。缺失且不会改变故事方向时，采用合理默认值，不追问。

- 时长和画幅
- 一镜到底或多镜头
- 写实、武侠、超级英雄、机甲或巨兽等战斗类型
- 角色与参考图的对应关系
- 场景、武器、胜负结果和暴力尺度
- 是否需要对白、音乐或纯音效

常用默认值为15秒、16比9、24fps、电影写实、环境音效优先。

### 2. 选择镜头结构

根据战斗规模选择一种结构，全文保持一致。

- 狭窄空间、近身格斗和短追逐优先用一镜到底
- 巨兽战、空战、大范围战场和强节奏蒙太奇优先用多镜头
- 用户要求一镜到底时，只允许摄影机连续跟随、环绕、降低、升高和甩动，不得安排编辑切镜
- 用户要求多镜头时，为每个镜头写独立时间、景别、机位、动作任务和承接状态

不要同时要求全程不切镜和多个无法连续到达的机位。

### 3. 锁定角色与物件

在时间线前建立连续性规则。

- 锁定人脸、发型、体型、服装、盔甲和显著配饰
- 说明每张参考图控制哪个角色或物件
- 写明武器由哪只手持有，何时掉落、拾取、损坏或易手
- 多名对手使用A、B、C等固定称呼，并要求外形彼此不同
- 记录开场已有的伤势、湿衣、灰尘、碎甲和装备状态

允许物理变化，例如衣服被雨淋湿、发丝贴脸和盔甲出现裂纹。禁止无原因的换脸、换装、武器复制和身体比例漂移。

### 4. 建立开场空间

先写清以下关系，再写交手。

- 主角在画面中的位置和朝向
- 对手从哪个方向进入
- 双方距离
- 门、墙、桌椅、车辆、积水或高低差的位置
- 人物的视线、落脚点和武器起始位置

空间复杂时使用画面左侧、画面右侧、前方、后方和具体距离。避免只写“敌人突然出现”。

### 5. 按动作容量拆分时间

15秒一镜到底通常安排4到6个主要动作。每2到4秒完成一个动作段。

每个动作段只承担一个主要任务，例如突袭、缴械、受挫、反击、决定性撞击或残局收束。给受击反应、身体恢复和镜头追赶留出时间。

多镜头可适当提高事件密度，但每个镜头仍只保留一个视觉重点。慢动作通常只用于一次关键撞击，持续约0.2到0.5秒。

### 6. 写出动作因果

每个动作单元按以下顺序组织。

```text
攻击发起 → 防守或闪避 → 身体接触 → 受击反应 → 环境反馈 → 下一动作起点
```

优先写可被演员实际完成的动词与身体部位。

```text
对手右拳挥向女主面部。女主向左侧头避开，左手扣住其手腕，右肘击中腹部。对手受击后向前弯腰。女主顺势按住其后颈，将他推向旁边的木桌。
```

使用“借助前冲惯性”“落地后继续旋转”“受击后踉跄一步”“弯腰后暴露肩背”等连接动作。不要把踢、摔、翻滚和夺刀写成互不相关的动作清单。

### 7. 让环境显示力量

每次关键撞击至少安排一种可见环境反馈，反馈必须符合材质与方向。

- 教室使用课桌位移、书本飞散、粉笔灰和黑板擦痕
- 雨巷使用积水、砖墙水滴、垃圾桶、纸箱、蒸汽和金属管道
- 雪地使用脚印、雪槽、雪粒、滑行痕迹和碎甲
- 巨兽战使用浪墙、地面裂纹、雾气扰动、建筑震动和大范围冲击波

环境反馈负责说明力量大小和运动方向。避免所有碰撞都用火花、爆炸或无来源烟雾。

### 8. 让镜头响应动作

镜头运动必须由人物或撞击触发。

```text
人物冲刺时，镜头从左后方贴身跟随。
武器从右侧进入时，镜头快速向右重新构图。
人物被击飞时，镜头先发生冲击震动，随后甩动追踪其飞行方向。
两人倒入积水后，镜头降低到近地面侧位，短暂失焦后重新锁定动作。
```

手持摄影可以有呼吸式抖动、撞击震动、轻微滚动快门和一次短暂失焦。保持主体动作可读，禁止持续无意义摇晃。

狭窄空间使用近距离跟拍和前景遮挡。巨兽战增加大全景和远景，持续显示体型差与破坏范围。

### 9. 用运动体现体型与能力差

不要只写身高数字。把差异写进运动速度、启动方式、覆盖范围和环境结果。

```text
女主贴近海面高速改变方向。巨兽缓慢抬起手臂，手掌宽度接近女主整个身体长度。巨掌击中海面后抬起环形浪墙。镜头在撞击发生时迅速拉远，同时显示女主的小型轮廓、巨掌和扩散水体。
```

小型角色可轻快、频繁变向。大型角色应有明显启动重量，动作幅度大，落点产生广泛反馈。

### 10. 设计节奏和结束状态

一段完整打斗至少包含一次压力变化。可以采用下列节奏。

```text
突袭 → 主角应对 → 对手增加压力 → 主角受挫 → 决定性反击 → 呼吸与残局
```

结尾写成可见状态，不用抽象情绪代替画面。

- 人物站、跪或倒在什么位置
- 武器在哪里，由谁持有
- 角色看向哪里
- 哪些物体已经损坏或翻倒
- 伤势、呼吸、衣服和天气维持什么状态

需要开放结尾时，让人物保持进攻或防守姿态，并让下一名对手进入攻击距离。

### 11. 编写声音

根据项目需要写环境底声、动作声和接触声。

```text
不使用音乐。保留暴雨、脚步踩水、急促呼吸和湿衣摩擦声。金属棍撞管道时出现短促回响，身体撞墙时为沉闷撞击声。环境雨声持续存在，不因攻击中断。
```

写实近身战优先保留真实环境音。大型奇幻战可增加低频轰鸣、能量聚集和远处爆炸，但不要让声音描述压过动作时间线。

### 12. 添加有针对性的负面限制

只写当前场景最可能发生的错误。

常用限制包括以下内容。

- 不得瞬移、穿模、肢体融合或无故飞起
- 不得复制人物、换脸、换装或改变体型
- 不得交换左右手或凭空增加武器
- 不得让倒地角色无原因重新出现
- 不得使用无意义慢动作、随机切镜和持续镜头乱晃
- 不得改变既定天气、光源方向和环境破坏状态

删除重复限制和互相冲突的指令。关键动作写清以后再补限制，不要用几十条禁令代替动作设计。

## 输出模板

根据用户需要删去不适用部分。交付可直接复制的成品提示词，不把内部分析混入提示词。

```text
[输出规格]
时长、画幅、帧率、一镜到底或多镜头

[参考资产与角色锁定]
参考图分工、人物外形、服装、体型、武器与开场状态

[场景与空间]
地点、人物朝向、距离、入口、出口与可互动环境

[战斗规则]
双方战斗方式、力量差、真实物理要求与暴力尺度

[动作时间线]
0到X秒 进攻、应对、接触结果、环境反馈与镜头响应
X到X秒 承接上一状态的下一组动作

[声音]
持续环境声、动作声和关键接触声

[连续性与负面限制]
身份、服装、武器、伤势、方位和破坏状态

[最终画面]
人物位置、姿态、视线、武器和环境状态
```

## 完整短案例

用户需要示范时，可以按以下密度编写，不要照抄角色与场景。

```text
超写实雨夜巷战，15秒，16比9，一镜到底，全程不切镜。

保持参考图女主的面部、黑色短发、身体比例、灰色机车夹克和黑色长裤一致。女主开场没有武器。对手A右手持一把伸缩棍。武器掉落后必须经过明确拾取才能易手。

场景位于狭窄后巷。画面左侧是湿润砖墙和金属管道，右侧有垃圾桶与纸箱，地面连续积水。雨水持续落下，巷道尽头有模糊霓虹灯。

0到4秒。镜头从女主左后方贴身跟随。对手A从正前方冲来，挥动伸缩棍横扫她的头部。女主压低身体从棍下穿过，左手按住对手手腕，右肘击中其腹部。对手向前弯腰。女主顺势用肩膀将他撞向左侧砖墙。对手后背撞墙，墙面水滴散开，伸缩棍脱手落入积水。

4到9秒。镜头降低到腰部位置。女主用右脚将伸缩棍挑起，右手在半空接住。对手B从画面右侧挥拳击中她的左肩。女主身体向左偏转，踉跄一步，随后利用转身让伸缩棍击中对手B大腿外侧。对手失去平衡，撞翻垃圾桶。

9到13秒。对手A从墙边重新扑来。女主向后跨步卸力，抓住其肩膀，借前冲惯性转身将他推向金属管道。对手肩背撞上管道，蒸汽晃动。女主用棍柄击中其腹部，对手弯腰跪入积水。

13到15秒。镜头贴近地面，短暂被水滴遮挡后重新锁定女主。她后退半步，右手仍持伸缩棍，低头急促喘息。镜头缓慢后拉，展示倒地对手、翻倒的垃圾桶和持续落下的雨。女主转身走向巷道深处。

全程使用近距离手持纪实摄影。镜头随奔跑与撞击自然抖动，允许一次短暂失焦，不得持续无意义摇晃。不要慢动作，不要编辑切镜。只保留暴雨、踩水、喘息、湿衣摩擦、身体撞墙和金属管道回响。
```

## 交付前检查

逐项检查并直接修正，不把检查过程交给用户。

- 每个动作能否由演员连续完成
- 每次攻击是否写明方向、接触点和受击反应
- 下一动作是否继承上一动作的姿势、距离与重心
- 镜头能否在规定时间内到达下一机位
- 武器、伤势、倒地人物和环境破坏是否连续
- 15秒内是否塞入过多动作、慢镜头或镜头变化
- 风格词和导演参考是否抢占了动作信息
- 是否存在重复句、武器名称变化或互相矛盾的限制

当用户只提供一个故事概念时，先补齐合理的动作与空间设计，再交付成品。用户要求诊断时，指出具体冲突与失败原因，不擅自改写。用户要求优化或重写时，直接修正并给出可复制版本。
